# Report Catalog

**Phase:** 9 | **Status:** Draft for review | Consolidates every module's §10 report list into the registered catalog (BR-RPT-001).

**Legend — Class:** Std = standard · PD = personal data (Export permission + T0) · 🔒 = restricted category · Stat = statutory/ministry (country pack) · Off = official document layout (school identity + signatory).
**Type:** Op = operational (daily work) · Reg = register (permanent record/audit) · An = analytical (trends/management) · Doc = printable official output.

Total: **228 reports.** Every report obeys BR-RPT-002 scope enforcement and BR-RPT-004 bilingual/RTL output.
