## 1. الصورة الكلية في ثلاثة أسطر

- **المحرّكات: 36/36 مبنية.** المراحل S0–S8 كلها مُنجزة — كل وحدة لها Domain + Application + Infrastructure واختبارات (1240 اختباراً أخضر). لا توجد وحدة «غير مبنية».
- **الفجوة كلها في طبقة الشاشات:** 19 وحدة لها شاشات كاملة، و**17 وحدة محرّكها جاهز بلا أي شاشة** — الشريط الجانبي يوجّهها لصفحة placeholder.
- **الجاهزية التشغيلية إذن مسألة «كشف المحرّكات بواجهات»**، لا بناء منطق جديد — وهذا أرخص بكثير: نمط المتحكّم/المشهد مستقر ومكرَّر 19 مرة.

## 3. ماذا تعني «أول الأمور التشغيلية» — حلقة اليوم الدراسي

لتشغيل مدرسة فعلياً يلزم إغلاق حلقتين:

```
الحلقة اليومية:   حضور → متابعة تأخير/استئذان → ملاحظات سلوك → تواصل مع ولي الأمر
الحلقة المالية:   رسوم → أقساط → تحصيل → مطالبات → ترحيل GL → تقارير للمدير
الحلقة الفصلية:  جدولة اختبارات → رصد → اعتماد → شهادات → ترحيل سنوي
```

**ما ينقص كل حلقة اليوم:**

| الحلقة | جاهز | الناقص |
|---|---|---|
| اليومية | حضور كامل (Capture/Gate/تأخير/استئذان/تبرير/تصحيح) ✅ | شاشات السلوك (M25) · المراسلات/الإشعارات (M32/M33) |
| المالية | رسوم + مدفوعات + خصومات + محاسبة مدمجة ✅ | **شاشات الأقساط (M20)** · شاشة تصدير GL · لوحة المدير (M31) |
| الفصلية | رصد واعتماد ونتائج (M17) ✅ | جدولة الاختبارات (M16) · الشهادات الرسمية (M18) · قمرة الترحيل |

## 4. فجوات تشغيلية ليست شاشات — لا تقل أهمية

| # | الفجوة | الأثر | الحجم |
